# YandexMusicMac 🎵

Ультра-легковесный, полностью нативный десктопный клиент Яндекс Музыки под macOS (Apple Silicon ARM64), написанный на **Swift 6** и **SwiftUI**.

Главная цель проекта — обеспечить полный функционал стриминга (включая «Мою волну», «Мне нравится», плейлисты, поиск, выбор качества вплоть до **FLAC Lossless** и системную интеграцию с macOS) при экстремально низком потреблении оперативной памяти (**целевой бюджет 40–70 МБ ОЗУ**) и нулевой нагрузке на CPU в фоне, полностью отказавшись от Electron, WebKit и WKWebView.

---

## 🚀 Ключевые особенности

* **Экстремальная легковесность:** Потребление ОЗУ в пределах 45–65 МБ благодаря аппаратному даунсемплингу обложек через `ImageIO`, лимитированному `NSCache` и разделению поисковых буферов.
* **Zero-WebKit Auth:** Авторизация через системный OAuth с мгновенным перехватом токена и гарантированной выгрузкой WebKit-процессов сразу после входа.
* **Двойной аудиопротокол и криптография:** Параллельное разрешение потоков (`/get-file-info` с HMAC-SHA256 подписью через `CryptoKit` и каталог `/download-info` с MD5-подписью) с поддержкой Hi-Res FLAC Lossless и 320 kbps.
* **«Моя волна» v2 + v1:** Бесконечный персональный поток на современном протоколе Rotor Session v2 с бесшовным fallback на v1 и полной телеметрией (`radioStarted` -> `trackStarted` -> `trackFinished` / `skip` / `like` / `dislike`).
* **Системная интеграция:** Нативная поддержка мультимедийных клавиш, Touch Bar, AirPods и виджета управления воспроизведением в **Control Center** (`MPNowPlayingInfoCenter` / `MPRemoteCommandCenter`).
* **Кросс-версионность:** Поддержка macOS 14.0 (Sonoma) и новее, полная совместимость со сборкой через стандартные Command Line Tools (CLT) без зависимости от макрос-плагинов Xcode.

---

## 🛠 Стек технологий

* **Язык:** Swift 6 (с включенным `StrictConcurrency`)
* **Интерфейс:** SwiftUI + AppKit (нативные таблицы `Table` для плавной работы со списками треков)
* **Архитектура:** Модульная структура на Swift Package Manager (`YandexMusicMac` + ядро `YMCore`)
* **Тестирование:** Нативный фреймворк `Swift Testing` (`YMCoreTests`)

## 📦 Сборка и установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GTE159/YandexMusicLite.git
   cd YandexMusicLite
   ```

2. Соберите проект в релизной конфигурации через Swift Package Manager или Xcode:
   ```bash
   swift build -c release
   ```

3. Исполняемый файл будет доступен по пути:
   ```bash
   .build/release/YandexMusicMac
   ```
